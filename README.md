# Распознавание номерных знаков (License Plate Recognition)

Пайплайн для детекции и распознавания номерных знаков на изображениях с использованием YOLO для детекции и CRNN для распознавания текста.

## 📊 Метрики и эксперименты

### Метрики детекции (YOLO)

После дообучения YOLO на датасете номерных знаков были получены следующие метрики:

| Метрика | Значение |
|---------|----------|
| **mAP@0.5** | 0.87942 (87.94%) |
| **mAP@0.5:0.95** | 0.3684 (36.84%) |
| **Precision** | 0.9023 (90.23%) |
| **Recall** | 0.8235 (82.35%) |

### Ограничения детекции

Модель показывает следующие ограничения:

1. **Ракурс съемки**: Плохо распознает знаки на фотографиях, где плоскость номерного знака находится почти перпендикулярно плоскости камеры
2. **Слишком близкое расстояние**: Не распознает номера на фотографиях, где машина находится очень близко к камере
3. **Художественное размытие**: Плохо работает на фотографиях с сильно размытым фоном (эффект открытой диафрагмы)

### Эксперименты с CRNN

#### Базовые параметры эксперимента

| Параметр | Значение |
|----------|----------|
| **BATCH_SIZE** | 32 |
| **IMG_HEIGHT** | 32 пикселя |
| **IMG_WIDTH** | 128 пикселей |
| **MAX_TRAIN_SAMPLES** | 3000 |
| **MAX_TEST_SAMPLES** | 300 |

#### Результаты экспериментов

| Эксперимент | Exact plate accuracy | Character accuracy |
|-------------|---------------------|--------------------|
| Понижен learning rate (1e-3 → 3e-4) | 8.67% | 66.72% |
| **Дефолт** (baseline) | **27.67%** | **83.16%** |
| **Расширена feature map до 512** + понижен LR (1e-3 → 3e-4) | **76.00%** | **94.11%** |
| Повышено разрешение (32×128 → 48×192) | 24.33% | 82.66% |

#### Анализ результатов

1. **Лучший результат**: Комбинация расширенной feature map (до 512) и сниженного learning rate (3e-4) показала наилучшие результаты:
   - Точность полного совпадения номера: **76.00%**
   - Поcимвольная точность: **94.11%**

2. **Пониженный learning rate без других изменений** ухудшил результаты
3. **Увеличение разрешения** не привело к улучшению
