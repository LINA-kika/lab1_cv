# Распознавание номерных знаков (License Plate Recognition)

Пайплайн для детекции и распознавания номерных знаков на изображениях с использованием YOLO для детекции и CRNN для распознавания текста.

### Метрики детекции (YOLO)

Размечено было 88 изображений (чуть более 20% от датасета, разметка есть в репозитории)

| Метрика | Значение |
|---------|----------|
| **mAP@0.5** | 0.87942 |
| **mAP@0.5:0.95** | 0.3684 |
| **Precision** | 0.9023 |
| **Recall** | 0.8235 |

### Ограничения детекции

Модель плохо распознаёт знаки на фотографиях, в которых плоскость знака находится почти перпендикулярно к плоскости камеры. А также не распознала фотографию, на которой машина была очень близко. Возможно повлияло ещё то, что фотография более художественная – на ней сильно размыт фон из-за открытой диафрагмы

### Эксперименты с CRNN

#### Базовые параметры эксперимента

| Параметр | Значение |
|----------|----------|
| **BATCH_SIZE** | 32 |
| **IMG_HEIGHT** | 32 пикселя |
| **IMG_WIDTH** | 128 пикселей |
| **MAX_TRAIN_SAMPLES** | 3000 |
| **MAX_TEST_SAMPLES** | 300 |

#### Результаты экспериментов

| Эксперимент | Exact plate accuracy | Character accuracy |
|-------------|---------------------|--------------------|
| Понижен learning rate (1e-3 → 3e-4) | 8.67% | 66.72% |
| **Дефолт** (baseline) | **27.67%** | **83.16%** |
| **Расширена feature map до 512** + понижен LR (1e-3 → 3e-4) | **76.00%** | **94.11%** |
| Повышено разрешение (32×128 → 48×192) | 24.33% | 82.66% |

Если при кропе изобаржения до передачу в OCR добавлять маленький отступ, то модель работает сильно хуже (не распознаёт до конца тест). Если запускать модель без отступов, то она распознаёт весь текст. Сравнение в файле final_pipeline_crop и final_pipeline
